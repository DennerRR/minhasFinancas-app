# Minhas Finanças: front-end (React)

Interface web do app de controle financeiro pessoal: login e cadastro de usuário, página inicial com o saldo e
consulta, cadastro, edição e mudança de status de lançamentos (receitas e despesas). Feita a partir de um curso de
Spring Boot com React.

**API (Spring Boot):** [DennerRR/SpringBoot-ReactJS](https://github.com/DennerRR/SpringBoot-ReactJS)

## Como executar

Pré-requisitos: Node.js e a API rodando em `http://localhost:8080`.

```bash
cd minhas-financas-app
npm install
npm start
```

O app abre em `http://localhost:3000`.

**Tecnologias:** React 17, React Router, Axios, Bootswatch (Bootstrap), Toastr.
